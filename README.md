# Ватка

Статический веб-прототип мессенджера.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий GitHub и загрузите в него эти файлы в корень ветки `main`.
2. Откройте **Settings → Pages**.
3. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
4. Через несколько минут сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Переписки, профиль и фотографии в этой версии хранятся только в браузере пользователя.
